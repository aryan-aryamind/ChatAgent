Embed a premium AI Agent Chatbot into your WordPress site in seconds. No coding required.

== Description ==

AI Agent Chatbot is a powerful, no-code solution that brings advanced artificial intelligence to your WordPress website. Connect your custom AI model to provide instant answers to your visitors, automate support, and increase engagement.

With a sleek, floating interface and smooth animations, this plugin offers a premium user experience out of the box.

= Key Features =
* **Instant Embedding**: Simply paste your Agent ID and Bot URL to get started.
* **Premium UI**: Modern, animated chat trigger and window.
* **No Code Required**: Completely beginner-friendly settings dashboard.
* **Custom AI**: Works with your existing AI Agent infrastructure.

== Installation ==

1. Upload the plugin folder to the `/wp-content/plugins/` directory, or install directly through the WordPress plugins screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Go to the **AI Agent** menu in your sidebar.
4. Enter your **Agent ID** and **Bot URL**.
5. Save changes and your chatbot will appear on your site instantly!

== Frequently Asked Questions ==

= Where do I find my Agent ID? =
You can find your Agent ID in your AI Agent dashboard under the 'Deploy' tab.

= Does this work with any theme? =
Yes, the floating widget is designed to be compatible with all modern WordPress themes.
